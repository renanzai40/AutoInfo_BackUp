## Original Content
<p>Hey HN! We built <a href="https://keenable.ai" rel="nofollow">https://keenable.ai</a>, a different web search API for AI agents.<p>Keenable searches our own 100B+ page index. We are focused on low cost and latency (p95 <250ms from us-east). We don’t believe in benchmaxxing, so we open-sourced our internal benchmarking suite, NEEDLE (available at <a href="https://keenableai.github.io/needle" rel="nofollow">https://keenableai.github.io/needle</a>): a live benchmark that compares Keenable with other search APIs on fresh agent-like queries.<p>I spent seven years at Amazon as a scientist working on web grounding for Alexa/AGI, and my co-founder Andrey previously led search at Yandex. We started Keenable because agents search differently from humans, and we wanted to build around those patterns directly.<p>The API is available now and we provide a free allowance of 100,000 requests a month.<p>It also exposes a novel SQL-like interface to the web, which is useful for structured extraction and agent workflows.<p>Happy to answer questions about the index, crawl, ranking, latency, or benchmarking.</p>

## Summary
Keenable is a web search API designed for AI agents, offering a 100B+ page index with low latency and cost. The company has open-sourced its benchmarking suite NEEDLE and provides a SQL-like interface for structured data extraction.

## Key Points
- Keenable is a web search API optimized for AI agents with low latency (p95 <250ms) and cost.
- The API utilizes an index of over 100 billion pages for comprehensive searches.
- An open-source benchmarking suite called NEEDLE is available for real-time comparison with other search APIs.
- The service features a novel SQL-like interface that facilitates structured extraction and agent workflows.
- The founders have extensive experience from major tech companies like Amazon and Yandex in search and AI development.
