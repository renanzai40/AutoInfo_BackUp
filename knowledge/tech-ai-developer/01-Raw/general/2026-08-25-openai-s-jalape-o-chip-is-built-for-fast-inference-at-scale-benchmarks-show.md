## Summary
OpenAI has developed the Jalapeño chip, a new technology designed for fast inference at scale. Benchmark tests reveal it outperforms current state-of-the-art chips in terms of tokens per user and throughput per kilowatt.

## Key Points
- Jalapeño chip is optimized for fast inference at scale
- It achieves higher tokens per user than existing chips
- It provides superior throughput per kilowatt compared to state-of-the-art alternatives
- Performance validated using SemiAnalysis’ InferenceX benchmark
